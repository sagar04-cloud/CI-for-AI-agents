# Assumptions

1. **Python Version Compatibility**: The local development machine has Python `3.10.11` installed on `PATH`. `pyproject.toml` sets `requires-python = ">=3.10"` while keeping all code 100% compatible with Python 3.11, 3.12, and 3.13 (tested in CI matrix). Using `from __future__ import annotations` where helpful and avoiding 3.11+-only stdlib features (`tomllib` fallback or `typing.Self` via `typing_extensions` / standard annotations) ensures local execution and CI parity.
2. **Repository & Author Metadata**: Repository is `https://github.com/sagar04-cloud/CI-for-AI-agents` (owner `sagar04-cloud`). Package name on PyPI and CLI entrypoint is `donegate`. Author placeholder `sagar04-cloud` is used in `pyproject.toml` and `LICENSE`.
3. **`llm_judge` Check**: To keep DoneGate's core deterministic and zero-LLM-dependency, `llm_judge` supports a configurable shell command or Python hook (or mock/env-configured endpoint) and never requires an LLM SDK in core dependencies. It is always marked lowest-trust and rejected if it is the sole check on a `must` (high-priority / required) task.
4. **Scope Guard Defaults**: `donegate check` defaults to `block` mode on out-of-scope edits (configurable per contract or CLI flag to `warn` or `revert-suggestion`). Common lockfiles (`package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `Cargo.lock`, `go.sum`, `poetry.lock`, `uv.lock`, `composer.lock`, `Gemfile.lock`) are auto-ignored by default unless explicitly listed in `scope.deny` or disabled via config.
5. **MCP Server (`integrate mcp`)**: Implemented with zero external MCP SDK dependency using standard JSON-RPC 2.0 over stdio, exposing `donegate_next`, `donegate_start`, `donegate_check`, and `donegate_status`.
6. **Virtual Environment**: Dependencies for local development and testing are installed inside a project-local `.venv/` rather than globally.
