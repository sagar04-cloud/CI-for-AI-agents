# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.
Report vulnerabilities privately via GitHub Security Advisories on
`https://github.com/sagar04-cloud/CI-for-AI-agents/security/advisories`.

Note: DoneGate executes shell commands defined in `done.yaml` (`command`, `test_suite`, `lint_clean`). Only run `donegate check` on `done.yaml` contracts from trusted repositories.
